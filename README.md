# 💱 Live Currency Converter

A simple and responsive web application that converts currencies using real-time exchange rates.

## 🚀 Live Demo
https://live-currency-converter-beta.vercel.app/

## 📌 Features

- Convert currencies instantly
- Real-time exchange rates
- User-friendly interface
- Responsive design
- Supports multiple currencies

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript (ES6)
- Exchange Rate API

## 📂 Project Structure

```
live-currency-converter/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

## ⚙️ How to Run Locally

1. Clone the repository

```bash
git clone https://github.com/rajeshxdev/live-currency-converter.git
```

2. Open the project folder

```bash
cd live-currency-converter
```

3. Open `index.html` in your browser.
